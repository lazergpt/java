# Сравнение Java IO, NIO и NIO.2

## Основные отличия по критериям: Java IO vs Java NIO

| Критерий                           | Java IO                                                                                     | Java NIO                                                                                                                       |
|------------------------------------|---------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------|
| **Ориентация**                     | Потоко-ориентированный (stream-oriented): данные читаются/пишутся побайтово последовательно | Буферо-ориентированный (buffer-oriented): данные читаются в буфер блоками; буфер явно управляется (`flip`, `clear`, `compact`) |
| **Режим операций**                 | Блокирующий: поток ждёт завершения чтения/записи                                            | Поддерживает неблокирующий режим: операция может вернуть управление сразу, если данных нет или буфер не готов                  |
| **Модель передачи данных**         | Потоки: `InputStream`/`OutputStream` (байты), `Reader`/`Writer` (символы)                   | Каналы: `FileChannel`, `SocketChannel`, `ServerSocketChannel` и др.                                                            |
| **Работа с множеством соединений** | Нужно по потоку на соединение (плохо масштабируется при тысячах клиентов)                   | Селекторы (`Selector`) позволяют одному потоку мониторить множество каналов и реагировать на готовность к чтению/записи        |
| **Управление памятью и доступом**  | Простой доступ; нет прямого контроля над буферизацией                                       | Есть прямые буферы (`DirectByteBuffer`) для эффективного взаимодействия с ОС; memory-mapped файлы через `MappedByteBuffer`     |
| **API и удобство**                 | Проще для простых задач (чтение файла, простой сетевой обмен)                               | Более низкоуровневый и многословный API; больше контроля, но выше порог входа                                                  |

## Преимущества и недостатки

|              | Преимущества                                                                                                                              | Недостатки                                                                                                                                                                |
|--------------|-------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Java IO**  | Простой и понятный API; низкий порог входа; хорош для простых задач                                                                       | Блокирующие операции; один поток на соединение; плохо масштабируется; нет memory-mapped файлов; нет работы с символическими ссылками                                      |
| **Java NIO** | Неблокирующий I/O; мультиплексирование через селекторы; memory-mapped файлы; прямые буферы для эффективности                              | Сложный API; ручное управление буфером (`flip`, `clear`, `compact`); высокий порог входа; нет удобного API для файловой системы                                           |
| **NIO.2**    | Современный `Path`/`Files` API; асинхронные каналы; `WatchService`; работа с атрибутами и ссылками; копирование/перемещение в одну строку | Асинхронный API требует колбэков или `Future` — сложнее в отладке; не все ОС одинаково поддерживают `WatchService`; больше не означает «новая замена IO» — это дополнение |

## Когда использовать

| Сценарий                                       | Рекомендуемый API                                              |
|------------------------------------------------|----------------------------------------------------------------|
| Чтение/запись небольшого файла, простой скрипт | Java IO                                                        |
| Высоконагруженный сервер с тысячами соединений | NIO + `Selector` или фреймворк на базе NIO (Netty)             |
| Работа с путями, копирование, обход директорий | NIO.2 (`Path`, `Files`)                                        |
| Асинхронный файловый/сетевой I/O с колбэками   | NIO.2 (`AsynchronousFileChannel`, `AsynchronousSocketChannel`) |
| Memory-mapped файлы                            | NIO (`MappedByteBuffer`)                                       |
| Наблюдение за изменениями в директории         | NIO.2 (`WatchService`)                                         |
| Реактивные системы (Spring WebFlux, Vert.x)    | NIO / NIO.2 через Netty или собственный transport              |

## Краткая справка

| Параметр                            | Java IO                                           | Java NIO                                            | Java NIO.2                                                                                  |
|-------------------------------------|---------------------------------------------------|-----------------------------------------------------|---------------------------------------------------------------------------------------------|
| **Пакет**                           | `java.io`                                         | `java.nio`, `java.nio.channels`, `java.nio.charset` | `java.nio.file`, `java.nio.file.attribute`, `java.nio.channels` (асинхронные)               |
| **Версия JDK**                      | JDK 1.0                                           | JDK 1.4                                             | JDK 7                                                                                       |
| **Парадигма**                       | Потоко-ориентированная (Stream-oriented)          | Буфер-ориентированная (Buffer-oriented)             | Буфер-ориентированная + расширенный API файловой системы                                    |
| **Режим I/O**                       | Блокирующий                                       | Блокирующий и неблокирующий                         | Блокирующий, неблокирующий и асинхронный                                                    |
| **Модель данных**                   | Потоки байтов/символов (`InputStream`, `Reader`)  | Каналы и буферы (`Channel`, `ByteBuffer`)           | Каналы, буферы + `Path`, `Files`, `FileSystem`                                              |
| **Масштабируемость**                | Один поток на соединение                          | Мультиплексирование через `Selector`                | Мультиплексирование + асинхронные каналы (`AsynchronousChannel`)                            |
| **Работа с путями**                 | `File` (строковый путь, громоздкий API)           | Нет отдельного API                                  | `Path` — современный, гибкий, поддерживает символические ссылки                             |
| **Файловые операции**               | `File`, `FileInputStream`, `FileOutputStream`     | `FileChannel`, `MappedByteBuffer`                   | `Files` — копирование, перемещение, проверка, атрибуты в одну строку                        |
| **Memory-mapped файлы**             | Нет                                               | `MappedByteBuffer` через `FileChannel.map()`        | Тот же механизм, унаследован от NIO                                                         |
| **Наблюдение за файловой системой** | Нет                                               | Нет                                                 | `WatchService` — отслеживание изменений в директориях                                       |
| **Асинхронный I/O**                 | Нет                                               | Нет (неблокирующий ≠ асинхронный)                   | `AsynchronousFileChannel`, `AsynchronousSocketChannel`, `AsynchronousServerSocketChannel`   |
| **Символьные кодировки**            | `InputStreamReader`, `OutputStreamWriter`         | `Charset`, `CharsetDecoder`, `CharsetEncoder`       | Тот же механизм + `Files.newBufferedReader(path, charset)`                                  |
| **Поддержка файловых атрибутов**    | Базовая (`File.lastModified()`, `File.canRead()`) | Нет отдельного API                                  | `Files.readAttributes()`, `BasicFileAttributes`, `PosixFileAttributes`, `DosFileAttributes` |
| **Символические и жёсткие ссылки**  | Не поддерживаются                                 | Не поддерживаются                                   | `Files.createSymbolicLink()`, `Files.createLink()`, `Files.isSymbolicLink()`                |
| **Копирование/перемещение файлов**  | Ручная реализация через потоки                    | Ручная реализация через каналы                      | `Files.copy()`, `Files.move()` — в одну строку                                              |
| **Обход директорий**                | `File.listFiles()`                                | Нет                                                 | `Files.walkFileTree()`, `Files.newDirectoryStream()`                                        |
| **Потокобезопасность**              | Потоки не thread-safe по умолчанию                | Буферы не thread-safe; селекторы — thread-safe      | Асинхронные каналы — thread-safe через `Future` и `CompletionHandler`                       |
| **Производительность**              | Низкая при большом числе соединений               | Высокая при мультиплексировании                     | Высокая + удобство разработки без потери производительности                                 |
| **Порог входа**                     | Низкий                                            | Высокий                                             | Средний (выше чем у IO, но ниже чем у NIO благодаря удобному API)                           |

## Когда использовать

| Сценарий                                       | Рекомендуемый API                                              |
|------------------------------------------------|----------------------------------------------------------------|
| Чтение/запись небольшого файла, простой скрипт | Java IO                                                        |
| Высоконагруженный сервер с тысячами соединений | NIO + `Selector` или фреймворк на базе NIO (Netty)             |
| Работа с путями, копирование, обход директорий | NIO.2 (`Path`, `Files`)                                        |
| Асинхронный файловый/сетевой I/O с колбэками   | NIO.2 (`AsynchronousFileChannel`, `AsynchronousSocketChannel`) |
| Memory-mapped файлы                            | NIO (`MappedByteBuffer`)                                       |
| Наблюдение за изменениями в директории         | NIO.2 (`WatchService`)                                         |
| Реактивные системы (Spring WebFlux, Vert.x)    | NIO / NIO.2 через Netty или собственный transport              |

## Ключевые классы и интерфейсы

| Java IO                               | Java NIO                                                | Java NIO.2                                                     |
|---------------------------------------|---------------------------------------------------------|----------------------------------------------------------------|
| `InputStream`, `OutputStream`         | `Channel`, `ReadableByteChannel`, `WritableByteChannel` | `AsynchronousChannel`, `AsynchronousFileChannel`               |
| `FileInputStream`, `FileOutputStream` | `FileChannel`                                           | `AsynchronousFileChannel`                                      |
| `Reader`, `Writer`                    | `Charset`, `CharsetDecoder`, `CharsetEncoder`           | `Files.newBufferedReader()`, `Files.newBufferedWriter()`       |
| `File`                                | —                                                       | `Path`, `Paths`                                                |
| `RandomAccessFile`                    | `FileChannel` + `MappedByteBuffer`                      | `AsynchronousFileChannel` + `ByteBuffer`                       |
| `ServerSocket`, `Socket`              | `ServerSocketChannel`, `SocketChannel`                  | `AsynchronousServerSocketChannel`, `AsynchronousSocketChannel` |
| `BufferedReader`, `PrintWriter`       | `ByteBuffer`, `CharBuffer`                              | `Files.readAllLines()`, `Files.write()`                        |
| —                                     | `Selector`                                              | —                                                              |
| —                                     | —                                                       | `WatchService`, `WatchKey`                                     |
| —                                     | —                                                       | `BasicFileAttributes`, `PosixFileAttributes`                   |
| —                                     | —                                                       | `FileSystem`, `FileStore`                                      |

> **Важно:** NIO.2 не заменяет NIO и IO — он их дополняет. В реальных проектах часто используются вместе: например,
`Path` из NIO.2 + `FileChannel` из NIO + `InputStream` из IO.
